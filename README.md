## MindMood — AI-Powered Therapeutic Chat Platform

MindMood is a full-stack AI therapeutic web application designed to help users improve their emotional well-being through personalized conversations. Built with **React**, **Tailwind CSS**, **Axios**, **Node.js**, **Express.js**, and **PostgreSQL (pgAdmin)**, it offers a seamless, modern chat experience fully integrated with the **OpenAI API**.

Users can sign up, complete an interactive onboarding flow, and receive tailored support from a virtual assistant. The platform securely stores user profiles, conversation summaries, and emotional insights while maintaining a smooth, continuous chat interface.

MindMood focuses on accessibility, clean design, and meaningful interaction — making mental-health support approachable and engaging.
